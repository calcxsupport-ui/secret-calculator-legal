# Secret Calculator — Legal

Privacy Policy and Terms of Use for the Secret Calculator iOS app.

## GitHub Pages

1. Create a **public** repository named `secret-calculator-legal` under `calcxsupport-ui`.
2. Push these files to the `main` branch (repo root).
3. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch** → Branch `main` / `/ (root)` → Save.
4. After a few minutes, open:
   - https://calcxsupport-ui.github.io/secret-calculator-legal/
   - https://calcxsupport-ui.github.io/secret-calculator-legal/privacy.html
   - https://calcxsupport-ui.github.io/secret-calculator-legal/terms.html

## App Store Connect

- **Privacy Policy URL:** `https://calcxsupport-ui.github.io/secret-calculator-legal/privacy.html`
- **Support email:** `calcxsupport@gmail.com`
- **App Privacy (nutrition labels):** while the app stays local-only with no analytics/accounts, you can declare **Data Not Collected**. Update this when adding RevenueCat or other SDKs that transmit data off-device.
